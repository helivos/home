Roles in one minute

There are three staff roles, plus members.

  • Admin can do everything, and is never restricted by permission switches.
  • Manager can see reports and send marketing. Some settings tabs are hidden from them.
  • Staff can run the day to day (members, inbox, check in, schedule) but cannot see revenue, marketing spend or send marketing.

An admin can also switch off whole areas for a single user in Settings > Users (Leads, Members, Retention, Inbox, Workflows, Schedule, Reports, Settings). If a sidebar item is missing for someone, this is usually why.

The gym can rename the three roles in Settings > Users, so a gym might call "Manager" something else. These articles use the default names.

Two things that trip people up

"At risk" means two different things. The Home dashboard card called At Risk (Churn) counts paying members who have not booked a class in the last 14 days (the window is adjustable). The High risk column on the Retention page comes from each member's health score, which looks at check-ins. They are separate on purpose, and they will not match. See Retention and Home dashboard.

Check-ins power almost everything. The risk levels, health score, milestones, motivation score, absent reports and visit counts are all built from classes members were checked into. If check-in is not being done, those numbers go quiet. See Check In.
